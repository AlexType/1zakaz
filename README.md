## Проверки фронтенда

Для `apps/web` используйте Node.js 24 LTS (версия закреплена в `.nvmrc`). После `npm ci` выполните `npm run lint`, `npm run format:check`, `npm run typecheck`, `npm run test` и `npm run build`. Те же проверки запускаются в GitHub Actions при изменениях фронтенда.
